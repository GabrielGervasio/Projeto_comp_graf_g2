# Cena 3D — Computação Gráfica

Cena interativa de uma mesa com cubos e esferas, iluminação por fragmento, luz *spot*, luz direcional, névoa e texturas de madeira.

## Como executar

Instale as dependências:

```bash
pip install -r requirements.txt
````
Execute a partir da pasta python:
````
cd python
python main_3d.py
````

Controles
Arraste o mouse: orbitar a câmera.

C: ativar/desativar o plano de corte.

L: ligar/desligar a segunda luz.

Q: fechar a janela.
